# Pine & Plane Woodworks

A standalone responsive MozingoUX portfolio concept. All business details, prices and contact details are fictional. No affiliation with real businesses.

## Run
Serve this folder with `python3 -m http.server 8000` and open http://localhost:8000. No build dependencies. Deploy the repository root through GitHub Pages.

## Features
Semantic landmarks, keyboard navigation, skip link, mobile navigation, reduced-motion support, native validated demo form. Forms do not transmit or store data.

## Images
Illustrative photography downloaded from images.unsplash.com and served locally.
